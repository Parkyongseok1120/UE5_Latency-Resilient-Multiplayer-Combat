# 사격·피격·사망 표현

사격 카메라 셰이크와 피격 화면 효과는 로컬 `PlayerController`의 `CombatFeedbackComponent`가 관리한다. 서버의 피해·탄약·명중 판정은 기존 전투 경로를 사용한다.

1인칭 카메라는 캡슐 중심에서 76cm 높이로 설정한다(기존64cm에서12cm상승). 총·팔은 카메라 기준4cm낮춰배치한다. 팔 전용 메시의 아래팔 뿌리 근처 열린 경계는 기존 스키닝 정점을 공유하는 단면으로 막았으며, 생성 도구를 재실행해도 닫힌 면을 중복 추가하지 않는다. 원본 Manny와 상대가 보는 몸 메시에는 적용하지 않는다.

- **사격:** 발사 가능 상태 검사를 통과한 로컬 발사에서 즉시 0.13초 카메라 셰이크를 시작한다. 동일 셰이크는 한 인스턴스를 재사용하므로 연사 중 무한히 중첩되지 않는다. 정조준 중 강도는 기본 55%다. 서버 승인 사격 multicast는 기존 무기·애니메이션 반동만 실행하고 셰이크를 다시 시작하지 않는다.
- **단발·연사:** 기본 라이플은 연사로 시작하고 `B`로 단발/연사를 전환한다. 단발은 새 클릭마다 한 발, 연사는 좌클릭을 누르는 동안 무기의 `FireRate`에 맞춰 발사한다. 떼거나 모드를 전환하면 반복 발사가 멈추고 다음 클릭부터 새 모드가 적용된다. 모드와 전환 revision을 소유자에게 복제하고, 아직 서버가 확인하지 않은 최신 로컬 전환을 이전 스냅샷이 덮어쓰지 않게 한다. 실험 커서가 켜져 있거나 사망한 동안에는 B 입력을 처리하지 않는다. 탄약 옆에 한글로 현재 모드를 표시한다.
- **탄약:** 기본 탄창은 30발, 예비탄은 330발로 초기 총 소지량은 360발이다. 재장전은 기존 서버 탄약 이동·보존 규칙을 사용한다.
- **조준:** 서버로 보내는 `AimRotation`은 컨트롤러 입력에서 읽는다. 셰이크가 포함된 최종 카메라 회전을 다시 조준 명령에 넣지 않는다.
- **피격:** 자신의 복제된 체력 또는 방어가 감소하면 화면 가장자리에 빨간 그라데이션 펄스가 나타나고 약 0.4초 동안 사라진다. 최초 관찰과 치유, 새 Pawn 생성은 피격으로 간주하지 않는다. 다른 플레이어의 체력 변화는 내 화면에 영향을 주지 않는다.
- **저체력:** 최대 체력의 50% 이하에서 글리치를 시작한다. 기본 최대 체력이 100일 때 51 HP에서는 효과가 없고, 50 HP부터 보이는 기본 강도(최대강도의 22%)를 적용한다. 이후 `lerp(0.22, 1, ((0.5 - 체력비율) × 2)^0.8) × 최대강도`로 증가한다. 화면 가장자리에 크기가 다른 세 겹의 사각 격자를 엇갈려 배치하고 빨강·주황·노랑·초록·청록·파랑·보라 스펙트럼 색을 빠르게 바꾼다. 각 블록의 영상 이동, 색 분리와 미세 노이즈도 가장자리 마스크 안에 집중된다. 체력이 낮을수록 블록 밀도·색상 합성·변위·갱신 빈도가 증가한다. 중앙은 블록과 색 분리의 영향을 받지 않는다. 치유하면 완화되고 사망하면 지속 글리치를 줄인다. HUD와 조준점은 후처리 뒤에 그려져 글자가 왜곡되지 않는다.
- **이동 사격:** `ABP_CombatRifle`은 하체에 기존 이동·점프 포즈를 유지하고 `spine_01` 위에 `Idle_ADS → DefaultSlot`을 메시 공간 회전으로 혼합한다. 사격·재장전 몽타주는 이 상체 슬롯을 사용한다. 기존 허리 조준 보정과 왼손 IK는 혼합된 최종 포즈에 적용한다.
- **1인칭 손·재장전:** `FirstPersonArms`는 소유자에게만 보이는 `SKM_CombatArms_Closed`를 사용한다. 원본 Manny를 복제한 뒤 손·아래팔 본의 스키닝 가중치가 우세한 면만 남기고 전체 스켈레톤과 손가락·재질을 보존한다. `CombatFirstPersonAnimInstance`가 기존 몸의 최종 포즈를 복사하고, 손 위치·회전을 유지하면서 1P 팔꿈치를 화면 아래로 굽혀 잘린 팔 끝이 화면에 떠 보이지 않게 한다. 매 프레임 오른손 소켓과 3P 무기 부착 오프셋의 역변환으로 1P 총에 정렬한다. 팔과 총이 같은 반동을 따르고, 재장전 시 총을 들어 기울여 손동작이 화면 안에 보이게 한다. `WeaponData.CharacterReloadAnimation`의 `MM_Rifle_Reload`를 복제된 `Reloading` 상태 진입 시 재생하며 원본 2.2초 모션을 실제 무기 `ReloadTime`에 맞춘다. 재장전 중 왼손 IK를 풀어 1P·3P 모두 손동작을 허용하고, 완료·취소·사망 시 표현을 정리한다. 팔은 충돌·그림자가 없고 다른 클라이언트와 서버 피해 판정에 노출되지 않는다. 사망 시 숨기고 새 Pawn은 새 팔을 구성한다.
- **사망:** 복제된 `Dead` 상태가 도착하면 `CharacterPresentationComponent`가 기존 `PA_Mannequin` 물리 에셋으로 메시 레그돌을 한 번 시작한다. 시체는 월드와 충돌하지만 플레이어 캡슐, 카메라, Visibility 사격 trace를 막지 않는다. 전용 서버는 메시 레그돌을 실행하지 않는다. 물리 자세 자체는 클라이언트별 시각 효과이므로 모든 클라이언트의 시체 관절이 정확히 같을 것을 보장하지 않는다.
- **리스폰:** 기존 Pawn은 정상 리스폰 경로에서 파괴되고 새 Pawn이 생성된다. 이전 카메라의 후처리와 활성 사격 셰이크를 정리하고 피격 펄스·글리치 강도를 초기화한다.

강도는 `CombatFeedbackComponent`의 `FireShakeScale`, `ADSShakeMultiplier`, `HitFadeSpeed`, `MaxGlitchIntensity`에서 조절한다. 기본 셰이크 진폭과 지속 시간은 `CombatFireCameraShake`에 있다. 후처리 머티리얼 `/Game/UI/Materials/M_CombatDamage`의 재생성 소스는 `Tools/CreateCombatFeedbackMaterial.py`다. 별도 이미지 텍스처 없이 현재 카메라 영상을 샘플링한다.

## 재검증

Editor 타깃을 빌드한 뒤 다음 명령으로 독립 서버와 두 렌더링 클라이언트를 실행한다.

```powershell
.\Tools\Start-FPSBaseline.ps1 -Benchmark -CombatFeedbackCheck -FireModeCheck -CaptureFrames -Samples 8 -LatencyMs 100
```

정상 사격·재장전·피해·사망·점수·리스폰 경로를 사용하며, 테스트용 피해 RPC는 추가하지 않는다. `Saved/CombatPresentation/Feedback/`에 피격·저체력·상대 레그돌 캡처를 남기고 `[CombatFeedbackCheck]` 로그에서 즉시 셰이크, 피격 펄스, 글리치 강도, 상대 물리 상태를 확인한다. C++ 자동화 `LatencyCombat.Feedback`는 로컬 카메라·피해 관찰·치유·타인 피격 격리와 레그돌/리스폰 경계를 검사한다.

`MovingAimCheck`는 먼저 이동하면서 상대 위쪽으로 발사한 뒤 정상 사격 계측을 진행한다. 상대가 보는 이동 사격의 총구 방향과 양쪽의 재장전 슬롯을 검사하고 `Saved/CombatPresentation/MovingReload/`에 1인칭 재장전·상대 재장전·상대 이동 사격 화면을 저장한다. `LatencyCombat.Animation.MovingUpperBodyAndReload`는 실제 바닥과 이동 입력으로 걷기·달리기 속도 및 상하 조준에서 총구 정렬, 왼손 접촉, 사격 중 하체 이동, 재장전 완료·취소·재진입·사망을 검사한다.

애니메이션 그래프와 재장전 참조만 갱신하려면 Editor 빌드 후 `Tools/ConfigureCombatAnimation.py`를 에디터 Python에서 실행한다. 전체 기본 에셋 생성기 `Tools/CreateCombatDefaultAssets.py`에도 동일 구성을 반영했다. 이미 상체 레이어가 있으면 다시 추가하지 않는다.

`FireModeCheck`는 독립 클라이언트에서 모드 전환 RPC와 실제 탄약 감소를 사용해 0.8초 동안 단발 한 발·연사 여러 발을 확인한다. `Saved/CombatPresentation/FireModes/`에 1P 손과 모드 표시를 캡처한다. `LatencyCombat.Weapon.SingleAutomaticToggle`은 중복 누르기, 전환 시 정지, 떼기, 재장전, 사망, 총360발을 검사하고, `LatencyCombat.Animation.FirstPersonHands`는 정면/상하 조준의 양손 접촉과 재장전·사망 경계를 검사한다. 팔 에셋은 `Tools/CreateCombatFirstPersonArms.py`로 재생성할 수 있다.

폭이 좁고 세로가 긴 화면은 위 명령에 `-WindowWidth 800 -WindowHeight 960`을 추가해 확인한다. 캡처 모드는 `-ForceRes`로 엔진의 편의 해상도 자동변경을 막아 지정한 크기를 유지한다.
